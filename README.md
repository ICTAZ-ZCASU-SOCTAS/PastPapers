## Contributing

Have papers we are missing? Add them.

<img src=".github/assets/contribute.svg" alt="1. Scan  2. Check  3. Name  4. Pull request" width="100%">

1. **Fork** this repository and add your PDFs to the matching folder, or create one using the existing pattern:
   `Undergraduate 2026 Sem 1`, `Postgraduate Deferred 2026 Sem 1`, `Undergraduate Mid Term Test 2026 Sem 1`.
2. **Name each file** `CODE TITLE TYPE.pdf`, matching the cover page:

   ```text
   CCS2131 DATA STRUCTURES AND ALGORITHMS FINAL EXAMINATION.pdf
   CIT4251 STRATEGIC IT MANAGEMENT DEFERRED EXAMINATION.pdf
   CAS5821 MATHEMATICAL FOUNDATIONS OF DATA SCIENCE MID TERM TEST.pdf
   ```

3. **Open every PDF before you upload it.** Exports from phones and SharePoint can quietly corrupt files.
4. **Open a pull request** to `main` describing what you added.

No GitHub account? [Open an issue](https://github.com/ICTAZ-ZCASU-SOCTAS/PastPapers/issues/new) and attach a zip, and a maintainer will add the papers for you.
